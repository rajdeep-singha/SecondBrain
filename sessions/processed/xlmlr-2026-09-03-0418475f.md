## Blockers & Lessons Learned — August 2026 Sprint

**Sprint theme:** accounting/permission hardening of the live StelloFi protocol on Stellar mainnet, a security-driven scope cut, and infrastructure repair. Contract test count went from **6 → 86**; all findings were fixed and redeployed by upgrade on 2026-08-31 with balances and holders preserved.

### Blockers encountered and resolved

- **A live accounting defect on mainnet.** The vault exchange rate read **5.69% higher** than the vault could actually pay: queued withdrawals burned shares but never recorded the XLM owed, so the denominator fell while the numerator didn't. This blocked any honest APY/TVL reporting until fixed. Resolved by recording the liability in the same call that burns shares; `migrate_v2()` reconstructed the existing liability from the on-chain queue — 38,114,885 stroops, matching prediction exactly.
- **A path that could inflate the rate with no assets behind it (critical).** `add_rewards()` credited a treasury balance without transferring XLM, and `withdraw_fees()` could then pay real XLM against it. Removed the stored counter entirely; `total_assets` is now derived from balances on every read (`idle + deployed − pending − treasury`), which eliminates the whole bug class rather than one instance.
- **Governance was decorative and bypassable.** Passed proposals wrote to storage no contract read; quorum was skipped; the backend re-applied parameters with the admin key. This blocked any credible decentralization claim. Rebuilt: escrowed voting against a creation-time supply snapshot, mandatory quorum, 24h timelock, and direct cross-contract execution. The admin-key backdoor and its four helper functions were deleted.
- **Toolchain build breaks in CI.** `ethnum 1.5.2` failed to compile on current `rustc` (E0512, invalid `mem::transmute`), breaking the contracts WASM build — fixed by bumping to 1.5.3. Separately, the Soroban RPC endpoint went dead and `stellar-sdk` was bumped to v17 to move off it.

### Outstanding blockers (carried into next milestone)

- **Single-key admin custody.** One Stellar account is admin on all five contracts *and* the keeper signing key. It can upgrade any contract and ignore every invariant above; there is no recovery path if compromised. **Moving to a multisig is the single highest-value open item** — an afternoon of work that converts an unrecoverable event into a survivable one.
- **Deployed source not verified.** On-chain bytecode cannot yet be matched to this repository (WASM sha256 hashes are recorded in the deployment register as the means to check). Free, ~one hour, and it's the first thing an auditor opens on.
- **Infra with no redundancy.** RPC and Horizon are single public endpoints with no fallback; TTL bumping depends on one backend staying up (~30-day archive risk). Only one of seven required monitoring alerts (solvency auto-pause) is actually live today.
- **Withdrawal-queue scale limit.** A single storage entry holds all requests and fails in the hundreds — unreachable at current volume but a known ceiling.

### Lessons learned

- **Derive state, don't store it.** Every rate-manipulation finding traced back to a stored numerator that could drift from real holdings. Computing `total_assets` from balances removed an entire class of bugs at once — a design principle we're now applying elsewhere.
- **Documentation drift is a security surface, not just a docs problem.** The published sXLM address was actually the native XLM asset contract; precision, an insurance fund, and an oracle stack were documented but never built. We cut the unbuilt subsystems (~2,765 lines removed: validators, leverage, restaking engines) and replaced aspirational claims with an honest *Current Limits* section. Under-promising in the docs is now a hard rule.
- **Rehearse upgrades against live state.** The mainnet upgrade was executed first against a testnet replica of live state; the liability reconstruction matching prediction to the stroop is what made the mainnet migration safe.
- **The cheapest audit wins are non-code.** The two items blocking a clean external-audit conversation (source verification and multisig) require no new contract code — a lesson that reshaped how we prioritize for the next milestone.

## General Comments and Outcomes

Going in, we thought August would be a feature sprint. It turned into something more honest: we sat down to audit our own accounting and permissions, and what we found changed the plan. The vault had been quietly overstating its exchange rate by 5.69% on mainnet — real money, already spoken for, showing up as if it were still there. Finding that on our own live contract was a gut check, but catching it ourselves (rather than a user or an auditor) is exactly the outcome we wanted from the review.

So the sprint became about earning back trust in the numbers. We stopped storing values that could drift and started deriving them from actual on-chain balances, which quietly closed off a whole family of bugs instead of patching them one at a time. We rebuilt governance from something decorative into something that actually controls the contracts, and we tore out the admin-key shortcut in the backend that had been undermining it. We also made a hard call to delete roughly 2,765 lines of features we'd documented but never really built — validators, leverage, restaking. It stung to cut them, but shipping honest docs matters more than an impressive feature list.

The concrete outcomes: contract test coverage went from 6 to 86, including invariant and attack-path tests; every finding was fixed and redeployed to mainnet by upgrade on 2026-08-31 with all balances and holders preserved; and the migration reconstructed the outstanding liability to the exact stroop, which is the moment we knew the fix was right.

We're not calling it done. The protocol is live and unaudited, custody still sits on a single key, and our monitoring and infra redundancy are thinner than we'd like. But we ended August with a codebase we can actually reason about, docs that match reality, and a short, honest list of what's left — which is a far better place to raise from than where we started.
